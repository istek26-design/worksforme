## [0.1.0] - 2026-10-06

### Added

- Static project and interpreter diagnostics with Rich/Typer CLI, health scores,
  actionable suggestions, schema-versioned JSON and documented exit codes.
- PEP 621, requirements, static setup.py, setup.cfg, Pipfile and basic Poetry parsing.
- AST import/provider mapping, standard library and local module filtering.
- Installed dependency version checks, exact-pin conflict and basic lock inventory checks.
- Environment variable name/presence checks and Git `.env` tracking/ignore warnings.
- Explicit venv-only pip repair plans, resolver preflight, default-No confirmation,
  dry-run and manual manager guidance.
- Check extension protocol, broken example, tests and cross-platform CI matrix.
- Apache-2.0 license, operational disclaimer, contribution/security policies,
  Contributor Covenant and issue/PR templates.
